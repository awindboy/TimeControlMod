# Mindustry Time Scale

싱글플레이에서 Mindustry 시뮬레이션 배속을 조절하는 iOS 호환 JavaScript 모드입니다.

## 기능

- 데스크톱: `F6` 배속 감소, `F7` 배속 증가, `F8` `1x` 초기화
- iOS/모바일: 좌측 상단 메뉴바 오른쪽의 `◀ / 배속 / ▶` 컨트롤 사용
- 데스크톱: HUD 오른쪽 아래의 `− / 배속 / +` 버튼 사용
- 지원 배속: `0.5x`, `1x`, `2x`, `4x`, `10x`
- 현재 배속을 HUD와 알림으로 표시
- 설정값 저장
- 멀티플레이에서는 자동 비활성화

모바일에서는 좌측 상단 기본 메뉴바 오른쪽의 화살표로 `0.5× → 1× → 2× → 4× → 10×`를 순환합니다. 기본 HUD를 숨기면 배속 컨트롤도 함께 숨겨집니다.

## iPad 설치

Mindustry의 모드 메뉴에서 `Import From GitHub`를 선택하고 아래 저장소를 입력합니다.

```text
awindboy/TimeControlMod
```

이 버전은 Java JAR가 아니라 `scripts/main.js`를 사용하는 스크립트 모드입니다. iOS에서는 `extend()`와 `JavaAdapter`를 사용하지 않는 스크립트만 호환 대상으로 표시할 수 있습니다.

`tests/`의 Java 파일은 iOS Rhino 호환성을 자동 검증하기 위한 테스트 대역일 뿐 모드에 포함되지 않으며, GitHub 언어 판정에서도 제외됩니다.

## 개발 기준

- Mindustry `v8 Build 159.7`
- Mindustry JavaScript scripting API

## 구조

```text
mod.hjson
scripts/main.js
```

기존 Java 모드는 `v0.1.1` 릴리스에 남아 있으며, 현재 기본 브랜치는 iPad 사용을 위한 스크립트 버전입니다. 저장소의 Java 소스는 GitHub의 자동 언어 판별이 Java 모드로 오인하지 않도록 기본 브랜치에서 제외했습니다. `v0.2.2`부터 데스크톱 UI 오버레이를 씬 최상위에 추가했고, `v0.2.3`에서는 배속 프리셋을 문자열로 저장해 설정 저장 오류를 수정했습니다. `v0.4.0`의 모바일 메뉴 방식은 실제 iPad에서 보이지 않아 제거했고, `v0.5.0`부터는 새 SwitchBlock 콘텐츠를 설치하고 탭하는 방식으로 모바일 조작을 처리합니다. `v0.5.1`에서는 스위치 상태를 블록 객체가 아닌 블록 이름과 활성화 필드로 판정하도록 수정했습니다. `v0.5.2`에서는 블록을 매 프레임 검색하지 않고 `ConfigEvent`를 직접 처리하며, iOS에서 문제가 될 수 있는 Java 콘텐츠 조회와 `Mathf` 오버로드 의존성도 제거했습니다. `v0.5.3`에서는 월드 업데이트 직전에 활성 블록을 재확인하고 `Time.delta`를 직접 적용해 iOS 프레임 루프 호환성을 보강했습니다. `v0.5.4`는 iPad에서 스크립트 실행과 블록 이벤트 수신 여부를 확인하는 임시 진단 토스트를 추가했습니다. `v0.5.5`에서는 시간 조작 코드보다 먼저 실행 여부를 확인하도록 진단 토스트 등록 순서를 앞당겼습니다. `v0.5.6`에서는 iOS Rhino 콜백 변환을 우회하려고 직접 콜백 방식을 도입했고, `v0.5.7`은 초기화 단계별 로그를 추가한 진단판입니다. `v0.5.8`에서는 iOS Rhino에서 Java `String` 클래스와 충돌하는 `print()`/`String(...)` 호출을 제거했습니다. `v0.5.9`에서는 Mindustry의 strict 래퍼와 iOS Rhino 인터프리터에서 콜백 인자·지역 변수 슬롯이 깨지는 현상을 동일 버전 Rhino로 재현했지만, 실제 Arc 159.7에 없는 `Time.timeScale` 필드를 테스트 대역에 잘못 추가해 로딩 종료 문제가 발생했습니다. `v0.5.10`은 테스트 대역을 실제 Arc `Time` API와 일치시키고, 월드 업데이트 직전에 지원되는 `Time.delta`만 배율만큼 조정하도록 바로잡았습니다. `v0.6.0`에서는 실제 Arc UI 클래스 기반 검사를 추가하고 모바일 배속 컨트롤을 도입했습니다. `v0.6.1`에서는 컨트롤을 기본 메뉴바 오른쪽으로 옮기고 배속 문자를 중앙 정렬했으며, 스위치 블록 방식을 제거했습니다.
